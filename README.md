# STM32F103C8T6 多功能时钟 · OLED 128×64（Keil uVision5 / ARMCC5）

一个跑在 **STM32F103C8T6**（72 MHz）上的完整小项目：流动表盘时钟、黑洞时间界面、倒计时、
烟花 + 跳舞小猫闹钟、设置界面（铃声 / 秒表），以及**浏览器模拟器**（在网页里运行同一份 C 代码）。

> 本次更新（V18）新增：**设置界面**（只有两个图标、钝角细线方框、选中方框闪烁）、
> **长按 PA4 两秒返回时间界面**、**返回后 1 秒防误触**、**秒表黑屏界面**、**浏览器模拟器**。
> 所有旧功能（流动表盘、黑洞界面、倒计时、LED、蜂鸣器、烟花、跳舞、生气动画）**全部保留并已回归验证**。

## 1. 硬件接线

| 功能 | 引脚 | 说明 |
|---|---|---|
| OLED SSD1306 | **PB6 = SCL, PB7 = SDA** | 软件 I2C，地址 0x78，页寻址 |
| 按键 PA4 | **PA4** | 上拉输入，按下为高（`KEY_ACTIVE_HIGH 1`） |
| 按键 PA5 | **PA5** | 同上；支持长按 2 秒（取消倒计时 / 进入） |
| 按键 PA6 | **PA6** | 倒计时 −1，长按连按 |
| 按键 PA7 | **PA7** | 倒计时 开始 |
| LED | **PC13** | 低电平点亮（`LED_On()` → BRR） |
| 蜂鸣器 | **PA8 → R5(10k) → Q1 PNP → 有源蜂鸣器** | **PA8 高 = 静音，PA8 低 = 响**（PNP 反相） |
| DS18B20 | **PA3** | 单总线，需 4.7 kΩ 上拉 |

> ⚠️ 蜂鸣器电路是 **高边 PNP**：上电瞬间 PA8 为高阻，请加 3V3 上拉电阻保证上电静音；
> 程序中已先把 PA8 预置为高电平再切换为推挽输出。

## 3. 界面与按键规则（实物 = 模拟器，完全一致）

### 3.1 时间界面（两个节目）
* 显示流动表盘；**PA4 短按** 在 `流动表盘 ⇄ 黑洞时间界面` 之间切换（带 1 秒形态过渡动画）。
* **PA5 短按 → 设置界面**（注意：不再直接进入倒计时）。

### 3.2 设置界面（本次新增）
```
┌────────────────┐   ┌────────────────┐        只有两个图标，没有任何中英文文字
│                │   │                │        ● 左：铃声（铃铛 + 4 道声波弧）
│    ( 铃铛 )    │   │   ( 秒表 )     │        ● 右：秒表（圆环表盘 + 12 点刻度 + 指针 + 轴心）
│                │   │                │        每个图标被一个【连续的、1 像素细线、
└────────────────┘   └────────────────┘        钝角（圆角 R=10）正方形】框住
```
* **PA4 短按**：切换选择（左 ⇄ 右）。**被选中那一格的外框闪烁（400 ms 亮 / 400 ms 灭），框内图案永不闪烁**；未被选中的外框常亮。
* **PA5 短按**：进入所选功能 —— 选「铃声」直接进入**倒计时界面**；选「秒表」直接进入**黑屏秒表界面**。
* **PA4 长按 2 秒**：返回时间界面。
* 每次打开设置界面，默认选中左边的「铃声」。

### 3.3 倒计时界面（原有功能，保持不变）
* 进入即显示时 : 分 : 秒 三组大数字（未输密码那种白边滚筒样式保留）。
* **PA4 短按** 切换「时 / 分 / 秒」编辑字段；**PA5 短按 +1**（长按连加）；**PA6 短按 −1**（长按连减）；**PA7 短按 开始**。
* 运行中 **PA5 短按** 切到进度界面，**PA5 长按 2 秒** 取消倒计时；**PA4 长按 2 秒** 回时间界面（倒计时继续走，LED 保持点亮）。
* 时间到：烟花绽放 + 小猫跳舞/打滚/生气动画 + 蜂鸣器节奏 + LED 闪烁；**任意按键**结束闹钟回到时间界面。

### 3.4 秒表界面（本次新增，黑屏）
* 选择「秒表」并按下 PA5 后，OLED 保持**全黑**（准备好后续开发）。
* **PA4 长按 2 秒** 返回时间界面。

### 3.5 防误触规则（重点）
* 从设置界面 / 倒计时界面 / 秒表界面返回时间界面后，**1 秒内 PA4 不会切换时间节目**，
  防止「长按 2 秒松手」的抖动或紧接着的误触把界面切走。1 秒后功能自动恢复。
* 长按 2 秒这一动作**不会**顺带触发短按功能（例如在设置界面长按返回，不会改变选中项）。

## 4. 浏览器模拟器（和实物一模一样）

模拟器里运行的不是“重写的 JS 动画”，而是把 **本工程的同一份 C 代码**编译成 WebAssembly 后执行的，
所以显示、时序、按键逻辑与实物完全一致（含 6.6 秒开机动画、1 秒过渡、闪烁相位）。

### 运行方法
```bash
cd simulator
python3 -m http.server 8000        # 或者任意静态服务器
# 浏览器打开 http://127.0.0.1:8000/index.html
```
页面功能：
* OLED 128×64 画布（1:1 显存直读，像素级还原）
* 4 个按键按钮（鼠标按住即可，支持键盘 A/S/D/F 或 1/2/3/4），按住 2 秒有**长按进度条**
* PC13 LED 指示灯、蜂鸣器指示灯 + 真实音效（WebAudio 2.5 kHz，可用「声音开/关」静音）
* 运行速度 0.5×/1×/2×/4×、DS18B20 温度滑杆、跳过开机动画、复位 MCU
* 实时状态栏（当前界面 / 时钟节目 / 设置选中 / 倒计时 / 防误触锁 / LED）与按键事件记录

### 重新编译 wasm（可选）
```bash
pip install ziglang          # 或系统安装 zig ≥ 0.13
bash simulator/build.sh      # 产出 simulator/fw_sim.wasm
```
`simulator/hal/stm32f10x.h` 只是给 wasm 用的外设桩（寄存器内存映射），
**Keil 工程完全不受影响**：Keil 依旧使用标准库的 `stm32f10x.h`。

## 6. Keil uVision5 使用提示
1. 把本仓库的 20 个 `.c/.h` 放进工程目录并全部加入工程（`simulator/` 不要加入！）。
2. 头文件路径只需工程根目录（头文件里都是 `#include "main.h"` / `"OELD.h"`，文件名保持原样 **OELD.h** 不要改名）。
3. C99 模式即可，无需任何特殊编译选项；`stm32f10x.h` 使用你本机的标准外设库。
4. 若 Flash 提示不足：本工程数据量较大（三套动画素材合计约 470 KB，
   需选择 **STM32F103C8T6 128 KB Flash** 的芯片或按需在 `main.h` 里关闭
   `YCAT_ROLL_ENABLED` / `YCAT_ANGRY_ENABLED`）。
5. 上电顺序：先给 PA8 上拉保证静音（见接线表）。
