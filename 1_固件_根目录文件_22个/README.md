## 1. 硬件接线

| 功能 | 引脚 | 说明 |
|---|---|---|
| OLED SSD1306 | **PB6 = SCL, PB7 = SDA** | 软件 I2C，地址 0x78，页寻址 |
| 按键 PA4 | **PA4** | 上拉输入，按下为高（`KEY_ACTIVE_HIGH 1`） |
| 按键 PA5 | **PA5** | 同上；支持长按 2 秒（取消倒计时 / 进入） |
| 按键 PA6 | **PA6** | 倒计时 −1，长按连按 |
| 按键 PA7 | **PA7** | 倒计时 开始 |
| LED | **PC13** | 低电平点亮（`LED_On()` → BRR） |
| 蜂鸣器 | **PA8 → R5(10k) → Q1 PNP → 有源蜂鸣器** | **PA8 高 = 静音，PA8 低 = 响**（PNP 反相） |
| DS18B20 | **PA3** | 单总线，需 4.7 kΩ 上拉 |

> ⚠️ 蜂鸣器电路是 **高边 PNP**：上电瞬间 PA8 为高阻，请加 3V3 上拉电阻保证上电静音；
> 程序中已先把 PA8 预置为高电平再切换为推挽输出。

## 3. 界面与按键规则（实物 = 模拟器，完全一致）

### 3.1 时间界面（两个节目）
* 显示流动表盘；**PA4 短按** 在 `流动表盘 ⇄ 黑洞时间界面` 之间切换（带 1 秒形态过渡动画）。
* **PA5 短按 → 设置界面**（注意：不再直接进入倒计时）。

### 3.2 设置界面（本次新增）
```
┌────────────────┐   ┌────────────────┐        只有两个图标，没有任何中英文文字
│                │   │                │        ● 左：铃声（铃铛 + 4 道声波弧）
│    ( 铃铛 )    │   │   ( 秒表 )     │        ● 右：秒表（圆环表盘 + 12 点刻度 + 指针 + 轴心）
│                │   │                │        每个图标被一个【连续的、1 像素细线、
└────────────────┘   └────────────────┘        钝角（圆角 R=10）正方形】框住
```
* **PA4 短按**：切换选择（左 ⇄ 右）。**被选中那一格的外框闪烁（400 ms 亮 / 400 ms 灭），框内图案永不闪烁**；未被选中的外框常亮。
* **PA5 短按**：进入所选功能 —— 选「铃声」直接进入**倒计时界面**；选「秒表」直接进入**黑屏秒表界面**。
* **PA4 长按 2 秒**：返回时间界面。
* 每次打开设置界面，默认选中左边的「铃声」。

### 3.3 倒计时界面 = 「铃声界面」（V20 密码锁重制）

```
                                    23:59 ← 右上角小号实时时间 (y=1..7)
  ┌───────────┐   ┌───────────┐   ┌───────────┐   ┌─────────────┐
  │    0 9    │   │    5 8    │   │    0 6    │   │             │   ← 上行: 值−1 (小字)
  │   1 0     │ : │   5 9     │ : │   0 7 ◄   │   │    Start    │   ← 中间: 当前值 (大字, 选中行)
  │    1 1    │   │    0 0    │   │    0 8    │   │             │   ← 下行: 值+1 (小字)
  └───────────┘   └───────────┘   └───────────┘   └─────────────┘
   y=12                                                       y=59
   ▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏▏  ← 运行时的进度条 (y=61)
```
* **布局**：黑色背景 + 纯白细线绘制；四个框都是「四条直边 + 四段四分之一圆弧」拼成的
  **连续 1 像素圆角(R=7)方框**，**统一 y = 12..59（高 48 px）、等高等宽对齐**，框间距恒为 6 px。
  数字框 25 px 宽，Start 框 33 px 宽。
* **数字（本轮重点修复）**：不再是 7 段拼凑，而是**连续折线笔画字体** ——
  每个数字都由 1～2 条折线组成（两条时相互**交叉**连接），因此
  **任何数字的任何一笔都不会断开**。大字 10×20 px / 2 px 圆头笔宽；
  小字是**同一套字形按 0.5 缩放**（5 px 宽 × 9 px 高 / 1 px 笔宽），
  上下行与中间行字形一致，一眼就能看出是同一个数字体系。
  > 旧版 7 段码字体的连通块实测为：0→6 块、1→2 块、2→5 块、3→5 块、4→4 块、
  > 5→5 块、6→6 块、7→3 块、8→7 块、9→6 块（10/10 断笔）。现在每个数字在两种尺寸下
  > **都恰好是 1 块**，并写进了自动化测试（`simulator/test/digits.mjs`）。
* **密码锁（鼓面）**：中间一行是**当前值（大号）**，上面一行是 **值−1**、下面一行是 **值+1**（小号），
  到边界**自动环绕**（秒/分 59→00、时 99→00；反向 00→59、00→99）。
  行与行之间留 2 行空白，中间行明显最大（墨量约为小字的两倍以上）。
* **滑动动画**：每次数值变化，三行**同向滑动**一个行距（17 px），用时 **140 ms**，
  离中心最近的变为大号 —— 就像真密码锁"值滚到中间"；动画结束回到**逐像素一致**的静态画面。
  滚动范围用 `OLED_SetClipRect` 卡死在框内，数字**永远不会溢出框外**。
  长按快速加减时每一步都重新触发滚动，于是看起来一直在连续旋转。
* **分隔**：时/分/秒 之间各用两个 2×2 的「:」点隔开。
* **字色**：纯黑/纯白；除 `Start` 外**没有任何中文或英文**。
* **实时时间**：右上角 `HH:MM` 小号字（5×7 点阵），与框顶之间留 4 行空白，**不遮挡任何内容**。
* **选中**：PA4 短按在「时 → 分 → 秒 → Start → 时」之间循环；**被选中的框 400ms 亮 / 400ms 灭闪烁，框内数字永不闪烁**。
* **数值**：PA5 = +1、PA6 = −1；**长按 2 秒进入快速加减**（100ms/步），再持续 2 秒后提速到 40ms/步；
  每次加减都会带动鼓面滑动（见上）。
  * 时字段每步 ±1 小时（00–99），分字段每步 ±1 分（00–59），秒字段每步 ±1 秒（00–59）
  * **进位/退位**：秒 59+1 → 秒 00、分 +1；分 59+1 → 分 00、时 +1；时 99+1 → 时 00；
    反向 00−1 → 分 59、时 −1，时 00−1 → 时 99（整体在 99:59:59 ⇄ 00:00:00 之间环绕）
  * 选中 Start 时 PA5/PA6 不再改动数值
* **开始**：选中 Start 后（或任何时候）按 **PA7 = Start** → 立即开始倒计时并**返回时间界面**，LED 常亮。
* **运行中界面**：设置界面 → 铃声 可再次进入；三个框显示**剩余时间**（大号，不再显示鼓面）、
  第 4 框显示**剩余百分比**、最底部 **y=61** 一条 1 像素细进度条（虚线轨道 + 实心进度，随进度填充）。
  **长按 2 秒 PA5** 取消倒计时。
* **返回**：任何倒计时界面下 **长按 2 秒 PA4** 回时间界面（运行中则倒计时继续走），并武装 1 秒 PA4 防误触。
* 倒计时结束 → 烟花 + 跳舞/打滚/生气动画 + 蜂鸣器节奏 + LED 闪烁（原有动画完全保留）。

### 3.4 秒表界面（V22 精修：大钟盘做到最大、上下贴着 OLED 边）

```
   ┌────────────────────────────┐   00:36.653  ← 右上 MM:SS.mmm (5x9 笔画字体)
   │  ╭──────────────────────╮  │   ⑤ 02.52    ← ①..⑨ 圆环 / ⑩.. 胶囊
   │  │    60 格刻度 · 细圆环 │  │   ④ 02.22      最新一圈在最上面
   │  ╰──────────────────────╯  │   ③ 01.92
   └────────────────────────────┘   ② 01.62
    大钟盘: 圆心 (32,32) 半径 31.5px, 四个切点 (32,0)(32,63)(0,32)(63,32) 都贴着 OLED 边框
```
* **大钟盘做到最大**：外环半径 31.5px（直径 63px），四个切点正好落在 `(32,0)`、`(32,63)`、
  `(0,32)`、`(63,32)` 的**像素中心**上 —— 上面、下面（以及左右）**都贴着 OLED 边框**。
  半径再大 0.5px，底部切点就会落到第 64 行（屏外）被裁掉，屏幕正中反而裂开 1px。
* **外环用极坐标 120 段圆弧逐段绘制**（`Sw_DrawRing`），不走整数中点圆：
  `OLED_DrawCircle` 在 R=32 时顶部是 11px 平顶、底部却在正中裂口，**上下不对称**；
  极坐标自绘的笔画恰好 1px 落在真圆上，且上下/左右严格镜像（实测最大半径 32.07px、0 处不对称）。
* **60 格刻度**：外端 r=30（离外环留 1.5px 呼吸感），短刻度 3px、每 5 格加长到 6px。
* **两根针**：总时间针（长 21px、2px 宽、针尖渐细到 1.5px、反向 7px 短尾）、
  分圈针（长 16px、细线 + 圆形端帽）。**每次分圈，分圈针立刻回到大钟盘最顶端（12 点）重新往下扫**
  （一圈 60 秒），一眼就能看出"这一圈已经跑了多久"。
* **计时器**：右上角 `MM:SS.mmm`（分 00–99、毫秒 3 位），自研 **5×9 圆角笔画字体**
  （1px 细笔画、逐格精确、绝不断笔），右对齐到 x=127，与下方分圈用时的右边界对齐。
* **分圈**：PA6 记一圈、**无限次**（环形缓冲保留最近 100 圈，圈号继续递增）；
  每行 = 圈号标记 + 该圈用时（<60s → `SS.hh`，≥60s → `M:SS.hh`，≥100min → `MM:SS.hh`），
  用时紧跟圈号左对齐（一列整齐），超长用时才改为右对齐贴边。
* **PA7 翻找历史**：被翻找那一行的**圈号数字 400ms 闪烁**（圆环不闪 → 行永远对齐），
  3 秒无操作自动回到"跟随最新一圈"。
* **PA5**：开始 ⇄ 暂停 →（再按）**从头开始并清空分圈记录**；到 **99:59.999** 自动停住。
* **退出**：长按 2 秒 PA4 回时间界面（**计时继续走**），之后 1 秒防误触。界面**零中英文**。
* **流畅丝滑**：脏区局部刷新（每帧平均 63 字节 / 16 次传输，实测 ≈0.002 ms/帧 CPU），
  指针角度 65536 分辨率（亚像素），毫秒位每帧只重画变化的字符格，静态表盘只在进入时画一次。
* **零残影保证**：所有墨水都用"**以针尖为圆心的圆**"绘制（端帽也是圆、不是方块），
  擦除笔半径严格更大（墨水最大半径 1.125px < 擦除 1.5px），几何上保证每一帧都能擦净；
  测试 G13 连续扫 15 秒**逐像素**验证盘内没有任何残影。

### 3.4b 设置2：计算器 / 游戏（V23 新增，时间界面按 PA6 进入）

```
   ┌──────────────────────────────┐
   │  ┌──────────┐  ┌──────────┐  │   背景纯黑; 两个 48x48 细线钝角方框
   │  │ 计算器   │  │  游戏    │  │   左 = 计算器图标, 右 = 游戏手柄图标
   │  └──────────┘  └──────────┘  │   被选中的方框 400ms 闪烁; 屏幕上零文字
   └──────────────────────────────┘
```
* **进入**：时间界面**短按 PA6**（PA5 仍是原来的设置1，两者互不影响）。
* **选择**：短按 **PA4** 在计算器 ⇄ 游戏之间切换，**被选中的细线方框闪烁**（400ms，与设置1 同一节奏）。
* **进入**：短按 **PA5** → 选中计算器则进计算器；选中游戏则进**纯黑占位界面**（后续再开发）。
* **退出**：长按 2 秒 **PA4** 回时间界面，之后 1 秒 PA4 防误触（与其它界面完全一致）。
* 两个图标都是**手工单色线描**（实心白机身 + 挖黑的显示窗/按键/十字键），与铃声、秒表图标同一风格。

### 3.4c 计算器界面（V23 新增）

```
   ┌──────┬────────────────────────────────────────┐  6 行 x 4 列
   │  AC  │                     12+34             │  行0: [AC] + 实时显示行(大方框, 右对齐)
   ├──────┼──────┬──────┬──────┤
   │  7   │  8   │  9   │  ÷   │  行1..4: 16 个按键
   ├──────┼──────┼──────┼──────┤  行5: [清空] + 3 个空格
   │  4   │  5   │  6   │  ×   │
   ├──────┼──────┼──────┼──────┤  · 每个按键都有一个**直角方框**
   │  1   │  2   │  3   │  −   │  · 被选中的方框 400ms 闪烁
   ├──────┼──────┼──────┼──────┤  · 左上 AC = 退回前一步(无限退回)
   │  0   │  .   │  =   │  +   │  · 左下 = 清空实时计算数据
   ├──────┼──────┴──────┴──────┤
   │ 清空 │        (3 个空格)   │
   └──────┴─────────────────────┘
```
* **按键**：**PA5 = 向左**、**PA6 = 向下**（走到边界会循环绕回，永远不会卡住、永远落不到空格子）；
  **PA7 = 确认**，选中的数字/符号立刻出现在最上面一行；**短按 PA4** 在显示行里**前后移动光标**（可以在中间插入/修改）。
* **AC（左上）= 退回前一步**，可以**无限退回**直到一开始。
  实现方式：整个计算器状态是**按键日志的纯函数**（每一步都记录了按键和当时的光标），
  AC 就是"日志长度减一 + 完整重放"，所以每一退都精确回到当时的样子（测试逐步比对 20 步）。
* **清空（左下）= 清掉实时计算数据**（表达式与日志一起清空）。
* **算术内核（全程整数，零浮点）**：`值 = 尾数 × 10^指数`，尾数 9 位有效数字；
  加减对齐指数用 int64，乘除用 int64（除法的商保留 10 位再归一化）。
  因此 **0.1 + 0.2 精确等于 0.3**（不会出现 0.30000000000000004）。
* **显示**：计算结果**只显示数值本身**（不显示过程）；**最多 8 位小数**，
  位数/小数位太多时按 **9 位有效数字**收敛并去掉末尾的 0（例如 `10/8 → 1.25`，`1/3 → 0.33333333`）；
  整数超过 10 位或除零显示 `Error`。
* **结果之后**：按任意键（PA4/PA5/PA6/PA7）都会**先清掉结果**，从新计算。
* **退出**：长按 2 秒 PA4 回时间界面 + 1 秒防误触。

### 3.4d Flash 瘦身：动画资源 103 KB → 80 KB（V24，画面逐位不变）

* **问题**：三段动画的原始差分流合计 103,102 B，整机 142,120 B，**超出 128 KB 芯片 10,972 B**，
  在 Keil 里会直接报 Flash 不足。
* **做法**：不删帧、不降分辨率、不改动画格式 —— 只把"从 Flash 直接读 1 位"换成
  **静态上下文二进制算术解码**（LZMA range coder + 8 位概率表，表 2,158 B 烧在 Flash 里）。
  解码出来的比特序列与旧格式**完全相同**，因此画面**逐位不变**。
  每帧一个独立码块、`offsets[]` 仍是字节偏移 → 任意帧可独立解码，乒乓/倒放不需要任何模型状态。
* **收益**：三段数据 103,102 → **80,310 B**（流 78,152 + 概率表 2,158）；
  整机 **142,120 → 120,453 B（117.6 KB）**，128 KB 下余量 **10,619 B**；**RAM 零增加**。
* **速度**：每帧 0.2~0.6 ms（30 fps 的帧预算是 33 ms），流畅度不受影响。
* **校验**：`simulator/test/cat_frames.mjs` 把三段动画 **640 帧**与"旧位流解码结果"逐帧比对；
  `python3 simulator/tools/gen_ycat.py --check` 还能证明"重新编码与存储逐字节相同"。

### 3.4e 花屏修复：整屏刷新必须自己声明寻址模式（V25）

* **现象**：秒表 / 计算器界面**长按 PA4 两秒**回到时间界面时，屏幕会花掉（约 7 页留着旧画面、
  1 页被新内容覆盖）。只有真机会花，浏览器模拟器一直是好的 —— 这也是它藏了这么久的原因。
* **根因**（两层）：
  1. `OLED_UpdatePartial()` 为了逐页局部刷新，会给面板发 `0x20,0x02` 把 SSD1306 切到**页寻址**，
     并且之后不再切回来。而 `OLED_Update()`（整屏刷新）只发了列/页窗口 `0x21/0x22` —— 这两个命令
     **在页寻址模式下是无效的**。于是 1024 字节从"当前页当前列"开始写，写满第 127 列后**回绕到同一页**：
     7 页停留旧画面、1 页被反复覆盖，这就是花屏。
  2. 模拟器里的"总线影子"把命令参数存进了错误的下标（`s_busArgTmp[2-argN]`），只有 1 个参数的
     `0x20` 参数落在 `tmp[1]` 却仍从 `tmp[0]` 读，于是影子**永远认为面板处于水平寻址** ——
     真机的 bug 在模拟器里被静默吃掉了。
* **修法**：
  * `OLED_Update()` 在控制字节 `0x00` 之后**显式**发 `0x20,0x00`（回到水平寻址）再设窗口。
    整屏刷新不再依赖上一次刷新留下的副作用 —— 这才是"一次刷新只对自己负责"的正确写法。
  * 影子模型改成按**到达顺序**编号（`s_busArgI`），并且页寻址下列号回绕到 0、页号不前进，
    与 SSD1306 数据手册一致。现在模拟器能**复现**这个 bug 了（撤掉修复后 35 项里 14 项立刻红）。
* **代价**：每次整屏刷新多 2 个字节（`0x20,0x00`），Flash +12 B，无视觉/时序影响。
* **回归**：`simulator/test/panel_sync.mjs` —— 秒表/计算器/游戏占位/设置1/倒计时/闹钟
  每一条"部分刷新 → 整屏刷新"的往返路径，都要求**面板 1024 字节与固件显存逐字节相同**，
  且同一屏反复进出 3 次仍然相同。`run_all.sh` 已把它收进第 6 步。

### 3.4f 设置3 + 日期/时间编辑器（V26 新增，V27 精修）
**进入**：时间界面按 **PA7** → 设置3（左齿轮 = 日期时间设置，右放大镜 = "访问"，功能后续开发，本次为真黑屏占位）。
PA4 在两个图标之间切换（选中项外框 400 ms 闪烁），**PA5 进入**，**长按 PA4 2 秒回时间界面**（随后 1 秒 PA4 防误触）。

**齿轮 → 日期/时间编辑器**（初值 = 当前系统时间）：

```
┌──────────┐ ┌────────┐ ┌────────┐      ← 年 / 月 / 日  三个"日历外围"
│  2026    │ │  05    │ │  17    │         (钝角边框 + 顶部两个装订环,
└──────────┘ └────────┘ └────────┘          比例来自参考照片的逐像素实测)
┌────┐ ┌────┐ ┌────┐ ┌──────┐
│ 23 │ │ 56 │ │ 25 │ │ SUN  │           ← V28: 时 / 分 / 秒 **各自一个**细线框,
└────┘ └────┘ └────┘ └──────┘              中间用冒号隔开; 右边是星期日历框
```
> 下排几何：三个框 x = **0 / 29 / 58**（宽 23），间隔 6 px；冒号两点落在
> x=25 与 x=54，y=48 / 54，各 2×2 px。窗口取框内 1 px 的 21 px 宽，两位数字 11 px
> 正好居中；三个框互不重叠，闪烁只擦自己的框线。

| 按键 | 作用 |
|---|---|
| **PA4**（短按/抬起） | **年 → 月 → 日 → 时 → 分 → 秒 → 年**（V27：**星期不可选中**；V28：时/分/秒 各闪自己的框） |
| **PA5 / PA6** | 选中项 **下一页 / 上一页**（长按自动连翻）；月/日 越界自动夹取（1月31日 月+1 → 2月28/29日，12月31日 月+1 → 次年1月31日） |
| **PA7** | **保存** → 直接回时间界面，时间界面立刻按新值显示 |
| **长按 PA4 2 秒** | 放弃修改，回时间界面 |

* **星期自动推算**：星期 = f(年,月,日)（Sakamoto 算法），改日/月/年时星期框同步翻页，**永远不可单独修改**。
* **日历翻页特效（V27）**：值变化时一条**翻折线**在格内扫过——
  **PA5 从底部往上翻**（旧页留在上方被抬起、新数字从下方升起），
  **PA6 从顶部往下翻**（完全镜像）；折线上有 1px 纸边高光，`smoothstep` 缓动 220 ms。
  旧页**不做位移**（只裁切）：试过"向铰链收缩"的近似，在 5×10 小字形上会让新旧数字叠成一团。
* **刷新**：首帧一次整屏（1024 B / 25 ms），之后只重画变化的那一格（实测静置 380 B/s、
  一次翻页约 3.2 KB 摊在 220 ms 里 ≈ 6 ms/帧，远低于 16.6 ms 预算）。

### 3.5 防误触规则（重点）
* 从设置界面 / 倒计时界面 / 秒表界面返回时间界面后，**1 秒内 PA4 不会切换时间节目**，
  防止「长按 2 秒松手」的抖动或紧接着的误触把界面切走。1 秒后功能自动恢复。
* 长按 2 秒这一动作**不会**顺带触发短按功能（例如在设置界面长按返回，不会改变选中项）。

## 4. 浏览器模拟器（和实物一模一样）

页面功能：

2. 头文件路径：把 20 个文件放进工程的 `User\`、`Hardware\<模块>\` 目录（和原来一样），
   并保证 **`OLED.h` 所在目录在 Options for Target → C/C++ → Include Paths 里**。
   文件名就是 **`OLED.h`**（V29 起统一；如果你的工程里还叫 `OELD.h`，Windows 不区分大小写，
   不改名也能编过，但建议直接换成新的 `OLED.h`）。
3. C99 模式即可，无需任何特殊编译选项；`stm32f10x.h` 使用你本机的标准外设库。
4. Flash：V28 整机链接后为 **125,423 B（122.5 KB）**，128 KB 的 STM32F103C8T6
   **可以完整装下（余量 5,649 B）**，三套动画全部保留，不需要再关闭任何宏。
   体积明细与压缩方案见 §3.4d。
5. 上电顺序：先给 PA8 上拉保证静音（见接线表）。
